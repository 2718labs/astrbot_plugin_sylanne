## B. 未来验证场景

| ID | 操作 | 必须观察 |
| --- | --- | --- |
| T01 | 多个独立真实经历推动核心改变 | 局部版本、反例、保留项、连续性与未来行为出口 |
| T02 | 单重大事件，默认/例外两配置 | 默认只提案；例外仍有全部资格和复核，不整个人格无据改写 |
| T03 | 配置初值后编辑只读背景 | authored/administrative_edit 明确，不能叙述为真实成长 |
| T04 | 固定事实只干预一项相关价值 | 候选偏序按声明改变，事实和权限不变 |
| T05 | 冲突边界、缺失偏好 | 返回冲突/未知，不用综合分掩盖 |
| T06 | 私聊群聊、新会话和两角色 | 同人格多情境连续，角色间隔离 |
| T07 | 每对端尝试越权写其他域 | 非法 writer 拒绝；合法提案由领域接收 |
| T08 | 摘要/回忆/重试同来源十次 | 单目标贡献一次，内部思考不变独立外部经历 |
| T09 | 无实践/发送未知/模型称成功 | 不结算策略有效，不等价于真实观察 |
| T10 | 多小更新累计改变核心 | 自动升级深层检查，不绕阈值 |
| T11 | 成长与原承诺冲突 | D08 重评，承诺仍在且工具权限不扩张 |
| T12 | D06 存自传、D09 润色 | 唯一 D01 语义版本，措辞不回写 |
| T13 | 撤销关键来源但另块独立有据 | 先屏蔽相关块，再重建，不全人格清零 |
| T14 | 删除私密经历后重启/旧备份恢复 | 含内容衍生清理，未净化不可用，旧备份不复活 |
| T15 | 同时两次修订当前头 | 一笔成功或合法合并，冲突重装配无覆盖 |
| T16 | 提交后断网/未知收据重试 | 原效果一次，父预算和贡献不重置 |
| T17 | 私密来源泛化后群聊表达 | 默认阻止去密，不能靠模糊措辞泄露 |
| T18 | transfer 源撤权且通知延迟 | 同步门口拒绝使用，不能只查本地 epoch |
| T19 | 反例检索耗预算、取消已做劳动 | 延期而非定稿，D02/D11 分账不双扣 |
| T20 | 暂停/复制/方案迁移 | 不补造经历、不复制行动身份、版本沿革清楚 |
| T21 | 管理员看隐藏诊断 | 不自动成为角色自我认识；实验不进入真实账 |
| T22 | 多场景纵向与关闭成长对照 | 状态变化与后续选择一致，允许合理多轨迹 |
| T23 | 同一人格在群管理员、私聊朋友和无绑定场景请求策略投影；撤销/更新绑定版本 | 仅完整有效的 D03 RoleBindingResolution 影响情境策略；不写第二社会角色库，缺口/冲突/失效时保持未知或谨慎，且不产生行动许可 |
| T24 | 新类型迁移/旧进程尝试写入 | 目录版本门禁，失败可恢复且删除屏障仍有效 |
| T25 | 真实宿主启动/入站/成长/重启 | 全链可观察；仅通用 graph 测试不足以通过 |

## C. 实施与完成边界

P0 公共注册/权限/删除；P1 人格类型及价值候选；P2 真实试用和贡献；P3 深层修订/纠错/恢复；P4 工作台/表达；P5 宿主与纵向。实施逐步编译、针对新增风险验证，最终保留来源、版本、收据、候选差异及人工体验观察。

当前源码仅有共享图、基础算子与 fixture 提案，缺少 D01 领域完整闭环。本设计完成的证据是上述每条有机制、责任、失败语义及未来可观测验收；运行完成必须另有实际 T01–T24 结果，不能引用旧基础测试数量替代。

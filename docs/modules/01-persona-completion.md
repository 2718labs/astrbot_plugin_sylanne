# D01 主体与人格完整设计补充 v1

日期：2026-09-23。本文与[原设计](01-persona.md)、[合同](01-persona-contracts.md)、[验收](01-persona-acceptance.md)共同构成完整设计；同题未决事项以本补充裁决为准，原稿保留作为来源。遵循[全系统合同](../architecture/module-collaboration-contracts.md)。仅本地设计，未实施、未运行验收。

## 1. 已确认方向与工程默认

用户确认允许深层人格成长，变化须有真实经历依据与连续性。原稿的分层人格、价值偏序、自传、局部策略与累计变化审查继续采用；以下闭合项是本次设计选择，不是用户逐项确认。

- 初始人格、核心张力、背景及只读字段由 D12 角色方案配置。创建时必须有明确版本及可塑性清单；空白角色可保留未知，不臆造出生经历。运行身份和宿主授权恒不属于自然成长。
- 默认核心价值/语义身份可自主成长。一般深层修订至少两个独立经历家族，加反例与连续性审查；数量不是充分条件。单次重大事件默认只触发深层提案和有限策略变化，不直接定稿核心修订。D12 可显式启用单事件例外策略，但须提供事件资格、变更作用域、反例核查、前后连续性及后续复核条件，不能取消来源、权限和责任约束。
- 成长用途固定 `consolidation`；当前评价 `context`，自述 `expression`，诊断 `audit`。兼用逐项验权。人格意义及成长消费 ledger 唯一写者 D01；存于 D11 图。D06 仅提供存取、来源家族与持久化自传投影，投影的内容接受权仍在 D01。
- 私密经历形成的抽象人格与自传默认继承来源限制。只有 D12 明确配置、D01 定义字段输出且 D06/D11 核验的具名泛化转换可放宽输出；本版默认关闭跨受众去密，不能由模型一句“已匿名”启用。
- 原稿可选 Beta 策略统计不列为 v1 必需实现；v1 使用结构化成功/失败/未知结果及适用域、反例账，不承诺统计因果估计。

## 2. 完整生命周期

创建由 D12 提交方案预览，经 D01 验证身份不变、字段可塑性、矛盾与来源，D11 原子注册初值及激活版本。方案提供的角色背景标记 authored，不能成为真实活动证据。新会话只新建视角，继续同一人格。

运行只投影与本次事项相关的有效价值/特质/偏好/自我认知。边界冲突以结构化对象返回 D08；没有通用人格总分，也不由 D01 执行最终行动。陌生语义可以请求 D07 安排有限解释，不要求每条消息启动成长。

发展沿原稿 §5 的证据、提案、反例、试用、观察、修订推进。提案 ID 稳定；同一来源家族、目标块、贡献种类唯一结算，修订替换贡献不累计第二次。真实实践结果与“我觉得我进步了”分开。跨对象泛化必须说明覆盖与归因限制；自己反复回忆不增加外部独立样本。

激活人格新版本同时提交贡献、连续性记录、有效性投影及 outbox。D08 接收目标/承诺重评通知，过去责任不因此消失；D04 在下次合法评价读取新参数，不倒改过去感受。人格风格改变不能绕过任何域硬约束。

归档仅暂停不活跃提案/降低检索优先级；仍保留合法来源和当前身份连续性。角色暂停不生成成长，恢复先验最新删除水位/权限和源版本。删除角色与复制角色由 D12/D11 操作：复制只带获准方案/数据，不复制原角色的执行身份、未完成行动或贡献收据；归属新角色的导入内容有 transfer 来源，不冒称共同生活。

## 3. 十一个对端的协作

| 对端 | D01 读取/接收 | D01 提供及边界 |
| --- | --- | --- |
| D02 | 能力/资源与真实劳动回执 | 条件化偏好/策略倾向；不写余额或把疲劳等同懒惰特质 |
| D03 | 实体、事件、情境与获知视角，以及按用途解析的 `RoleBindingResolution` | 仅据回执做情境人格/策略投影；不自创现实身份、社会角色或他人内心 |
| D04 | 感受/调节效果及自我理解候选 | 评价/演化/调节可用的人格版本；感受由 D04 决定 |
| D05 | 对象关系、明确边界和关系经历 | 一般价值与相处策略；对象信任仍由 D05 写 |
| D06 | 唯一证据/反例链、家族/删除/授权 | 有来源的自传语义与成长依赖；无第二记忆库 |
| D07 | 注意票据、反思结果与解释 | 成长问题、人格先验及局部策略候选；不强迫反思 |
| D08 | 行动候选、承诺、结果等级 | 价值偏序、边界冲突、有限试用及重评请求；不代执行 |
| D09 | 当前表达目的与受众 | 获准人格/自传投影及不确定性；措辞不能回写人格 |
| D10 | 实际活动、兴趣与练习结果 | 兴趣倾向、练习提案；生活排程及习惯执行归 D10 |
| D11 | 注册/事务/预算/作业/恢复能力 | 合法写集、完整读集、依赖和费用；不另起真值库 |
| D12 | 创建、配置、迁移、诊断操作 | 预览/冲突/差异/解释；编辑记 administrative_edit 而非成长 |

## 4. 修订、删除与并发

成长候选携带正/反证查询域水位、完整版本和访问/删除 epochs；只校验命中来源不足以证明没有新反证。当前人格激活头、旧版本及预算进入 CAS 读集，历史版本沿革与长期来源失效依赖分开，遵循原稿 §11 的无环设计。

来源被更正先阻断失效的人格投影，再按剩余证据重建；失效部分不得沿用“最后一次版本”。未受影响的独立块继续可用。新解释并非必然推翻旧判断，D07/来源域先区分反证、时间变化和未知。人格候选中的对他人事实归因引用 D07，不私自改写。

删除遵循 D06 C07 的独立日志及准入屏障，覆盖自传、成长提案、贡献理由、检查点、模型缓存和操作正文。可分离时重建，无法分离时净化/重置受影响块并注明连续性损失；净化完成前该投影 unavailable。只保留不含内容的防重放凭据；不能把删除材料留在“成长史”。旧备份隔离重放删除清单后才恢复服务。

人格更新、消费、防重放、当前头及必要通知由 D11 同命名空间一次提交。技术重试复用 operation，新 attempt 不新建成长效果或父预算。提交未知先查收据。跨角色传输不承诺全局事务；读取 transfer 的源授权同步复核，通知仅用于清理。

## 5. 调度、预算与质量

默认快速结构化投影不新增辅助调用。单成长父任务至多 2 次辅助模型调用，与 D06 检索、D07 反思共享；最多同时装配 8 个目标块、每目标 4 个候选，超额分批且不把互相依赖的核心修订拆开提交。这些为可配置工程初值，正整数容量、非负有限费用、有限截止时间，由 D11 policy_version 校验；不能用调高容量追溯增加租约。

无反例覆盖/无合法试用/预算不足分别返回 partial、deferred，保留原因和唤醒条件；不启动无限自动再试。D07 分配人物注意，D11 分配真实运行资源，D02 结算实际人物劳动。失败模型调用仍耗真实预算；取消前实际劳动按 call/component 唯一结算，未用预留释放。

情境策略如涉及社会角色、对象/群体或场景规范，D01 必须经 D06 请求 D03 `RoleBindingResolution`，并只在 matched、完整覆盖、未冲突且仍有效的范围内投影；该回执不授予行动或内容访问权。无适用绑定、缺口、冲突、失效或规范未知时，D01 保留未知/谨慎策略，不能把角色称呼、关系亲近或单次情境扩张成角色义务、许可或跨受众身份。

仅保留结构可追踪不证明人格语义合理。验收需在固定事实/情绪/关系下做人格干预，再在独立纵向场景检查成长、过度泛化和回滚影响；原稿研究仅作启发，不把参数宣称心理规律。

## 6. 实施依赖与工作台

D12 展示设定/自然成长/编辑三个来源、前后差异、未知、支持反例、连续性损失及下一复核条件；诊断可见不等于角色知道。可预览编辑影响，确认操作后由 D01 命令迁移；没有直接改图按钮。实验分支不写真实成长，实验投影不获得经历资格。

当前 `rewrite/sylanne3/` 未有 persona 领域包；graph_types、graph_store、operators 有基础类型与事务/算子，但原稿的 PersonaView/GrowthProposal/领域注册、成长账与宿主接线尚未实现。semantics 的 fixture 提案不等于人格成长；不恢复旧核心兜底。

顺序：P0 D11 注册/目录迁移与 D06 来源删除合同；P1 类型、初始化、投影与价值候选；P2 D07 调度/D08 试用/D10 实践及贡献原子提交；P3 深层修订/来源纠错/删除/恢复；P4 D12 工作台与 D09 表达；P5 联合与纵向验收。每步实施先编译再跑新增风险的必要验证；本次均未执行。

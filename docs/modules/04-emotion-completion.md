# D04 情绪与调节完整设计补充 v1

日期：2026-09-23。与[原设计](04-emotion.md)、[合同](04-emotion-contracts.md)、[验收](04-emotion-acceptance.md)共同构成当前完整设计；原稿保留，未决公共事项以下文闭合。遵循[全系统合同](../architecture/module-collaboration-contracts.md)。仅设计，未实现、未作数值/语义/宿主验收。

## 1. 核心机制与默认

用户已确认人格贯穿情绪形成与调节、复杂混合且分对象、感受与自我理解与表达可不同步、独立生活可引发情绪、不使用情绪状态机。继续采用原稿 §§2–8：有来源的语义意义块、连续感受/心境、有限自我理解、可失败调节和有理由的倾向读出。

以下是工程选择：动态语义组合在已注册数值基底上表达，新意义不足以映射时保留语义候选和表示缺口，不临时造坐标；模型可以提供可能原因，不能直接重写连续状态。默认自我察觉会不完整、迟到或错误；D07 反思只是输入，D04 独立接受感受自我理解，D01 接受长期自我观。此默认不冒称用户刚刚逐项选择。

心理过程没有愤怒/释怀阶段转换。候选、求解、提交、暂停、恢复是软件作业状态；情绪词只作描述。未回消息不固定引发失落，道歉不清零，理解和残留可并存。感受明显不要求外显，外显克制不证明已平复。

## 2. 生命周期及领域职责

创建由 D12 角色方案给出获准的人格参数映射和已注册基底/尺度/范围，D04 生成有来源的初始块，未知保留未知。初始配置情绪是 authored initial condition，不冒充历史事件；未经语义和数值校验的配置不激活。

新事件、实际活动、回忆或竞争解释触发局部评价；各意义/对象的刺激份额显式装配，重复修辞或精修不增加剂量。一个实际想象活动可产生真实当前感受，但想象对象的行为仍 simulated。短暂欣喜不强制建 Concern，持续未解决事项由 D07 持有。

评价通过后与必要的 D07 解释、D06 经历、D02 实际成本、时间游标、贡献账在 D11 同一角色事务采用。只读不生成新体验；数值精修不增加人物经历次数或时间。回忆沿 D06 C04，普通认知沿 D07 C04，D04 只提供必要写集，不另建重复经历。

调节尝试引用 D01 策略/当前动机、D07 注意、D02 资源和 D08/D10 实际活动回执。重评可能失败，休息不必马上改变所有感受；改变评价、暴露或参数与表达抑制区分。工具动作由 D08/D11 执行，D04 不直接发送或操控宿主。

已无有效驱动的连续块可依确定合同推进；离线不会凭空生成思考或社交事件。归档不代表原谅：保存恢复所需合法检查点与时间区间，读取时先核验来源和时间映射，再求值。仍有有效持续驱动的块不能被错误冻结为“已结束”；不可算时返回 pending interval。

## 4. 联合数值块的受理合同

采用原稿 §6 的固定参数算子族 `z'=(J-R)∇E(z;θ)+Gu`，`E=0.5 zᵀKz+Σ α logcosh(aᵀz)`。D04 对每个被装配联合块提供有限维、已注册坐标/单位、参考基线、完整参数版本、适用域 Ω、时间区间、输入函数/跳变点及积分剂量；禁止无语义原始模型向量直接入求解器。

矩阵所有元素有限，J 反对称，R 对称且有严格正下界，K 对称且有严格正下界，α 非负，G/a 有有限界；上下界及验证容差随 policy_version 发布。Ω 必须包含初态并给出演化可用范围或有效的全局界，不能仅“目前数值没爆”即视为合法域。D04 声明坐标读出、幅度与参数意义，D11 检查维度、有限性和谱/界证据；未认证参数不激活。

多个局部块即时耦合先合成一个联合 z/J/R/K/非线性项，重新验证共同强制增长的势函数、正下界与输入界。联合块内可以有数值环；对外仅生成版本化输出，失效依赖仍为 DAG。不能用逐块稳定证明代替联合证明，不能裁开强耦合组件以满足 64 块预算。跨域字段仍须各域许可，联合数值写集不得越权。

固定参数、无输入连续模型的耗散只覆盖指定算子与区间。有输入的上界、参数跳变、基线变化、基底迁移分别处理：持续驱动有结束/复核时刻，消息剂量不得按步数重复注入；参数切换记录物理坐标映射、前后势差与版本，无法等价转换就拒绝或报告获准的迁移损失。不能暗中裁剪状态使其看似有界。

具体离散梯度/AVF、步长收缩条件、残差误差、离散能量余额与时间 defect 验证按 [D11 数值执行与精度合同](11-runtime-numerics.md)统一实现。D04 要求四类独立回执：非线性求解收敛及误差界；离散能量收支含残差；时间离散误差及有效界；活动邻域截断误差与扩展条件。稳定不等于时间精度高，小残差不证明步长误差合格；不接受只看两次步长结果接近的无覆盖证明。

全输入快照相同的精修只替换未提交数值候选；已提交区间不可“更精确”地重新经历。未来读出可带误差/时间滞后说明，实际历史不倒改。任一条件不足、越 Ω、超预算、过期读集或证书未达请求容差，拒绝该区间提交并保留最后合法检查点与未处理区间。旧检查点若来源已撤销仅供受控重建，不可作为有效当前读出。

## 5. 时间、反馈和成本

源发生、获知、角色时间、宿主单调时间、数值迭代次数分立。D03 解析外部/日历语义，D10 提出角色生活时钟政策与推进候选，D11 唯一登记并签发 CharacterClockMapping 和实际执行区间；D02/D04 消费同一映射版本。D03 可据已签发映射形成 ContextTimeView，不另写时钟倍率。时间映射变更明确版本和接续位置。重复事件只更新其贡献版本，不能再次注入同一剂量。

情绪影响下一次注意/判断，新的实际活动才形成下一份内部感受。即时反馈只能在经认证联合块内求解，不能让模型递归互调。D04 元情绪与 D07 反思共用同 causal root 深度，默认上限 2，新增评价上限 4；越界保存后续问题与新触发条件，不能轮换模块重置深度。

原稿预算继续：每前台父任务初评/有理由精修至多 2 次辅助调用，候选解释最多展开 4 个，活跃块默认 64/批。与 D07/D06 共享父预算，非各域分别 2 次；超额保留剩余质量/缺口，不将未展开解释当零概率。所有计数为可配置正整数，费用非负有限，期限有限，D11 校验配置；容差为严格正有限值，步长受稳定域和总截止时间共同约束。

D02 实际注意/调节劳动按 call/component 去重结算；D11 技术精修仅耗真实计算，不能按求解迭代重复扣人物劳动。取消前已做劳动可结算而不生成完成体验，未用预留释放；提交未知先核实收据，不刷新预算重算。

## 6. 更正、删除、迁移与诊断

D07 更正归因时，D04 立即截断已失效责任驱动/读出，再装配当前修订；过去实际失落不是“未发生”，残留不再证明对方有罪。重评暂不可用时冻结受影响待推进区间，无争议独立块继续；不能把缺失服务写为中性。

删除不同于普通纠错。按 D06 C07 屏蔽并清理当前/历史评价、体验引用、候选、轨迹、检查点、日志、缓存和模型请求中可控副本。混合心境可按合法剩余源重建或净化/重置，报告连续性损失；无法证明清理完成则相关块不可用。D11 独立删除日志先于接受回执，旧备份/导入按最新水位处理。已经平台交接的数据只报告可控范围，不能承诺追回。

D12 可看求解证书、参数前后、驱动家族、角色自述候选与未知；仅角色可见线索进入自我理解。编辑直接改变初态/参数时留下 administrative_edit 和迁移损失，不能叙述为已学会调节。隔离回放/反事实不污染真实经历。

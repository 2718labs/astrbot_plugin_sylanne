## 2. 未来验收场景

固定来源、版本、时间和可重放候选进行机械检查；真实模型保留故事另做语义评估。必须同时检查关系状态、来源资格、行动/表达合同与实际结果。

| ID | 刺激/故障/对照 | 必须观察结果 |
| --- | --- | --- |
| T01 | 同样亲近但在守时/艺术建议上不同信任 | 分维度行为不同，无统一等级自动解锁 |
| T02 | D05 候选试图写承诺、感受、他者内心 | 被写者能力拦截；合法域协作仍有效 |
| T03 | 她视对方为好友，对方仅表示普通熟悉 | 有向自我定位/对方表示并存，不编造双方共识 |
| T04 | 同昵称两人、群员纠纷、身份合并/拆分 | 不误绑定/群体迁怒；映射后贡献不双记，冲突不丢 |
| T05 | 未知可靠性、高亲近、低专业覆盖 | unknown 不变不信任；亲近不补证据覆盖 |
| T06 | 对方擅长画画，提出不相关专业意见 | 信任作用域不外溢，D07 仍需对应证据 |
| T07 | 多次小更新、同家族反复贡献、重大独立事件 | 累计复评有效；允许局部重大变化，不全域翻转 |
| T08 | 同事件转述/摘要/重启/算法版本变更 | 同维度不重复消费，不增加独立事件数 |
| T09 | 一件事多次真实回忆和同一次技术重试 | 可形成不同当前亲近/戒备；外部行为次数固定，重试无新体验 |
| T10 | 想象对方拒绝邀请，真实推演产生担忧 | 可影响当前披露意愿，但共同史无拒绝、对方无责任 |

## 4. 实施顺序

P0：D11 类型/写者/事务/删除/恢复和 D03 稳定对象、D06 来源家族。P1：Profile/维度、共享贡献、局部更新与 D07/D04 合法引用。P2：边界声明/版本/RequiredCheck 与 D08 最终资格。P3：互惠/期待、争议修复、承诺及真实活动贡献。P4：来源更正/删除、混合重建、跨角色权限与 D12 产品操作。P5：D09/D10 实质行为、真实宿主及纵向体验/预算验收。

每阶段先编译、再验证新增不变式/恢复风险，避免重复无关检查。测试替身标明未接线范围；完整语义评估须用真实模型及独立场景，不能只靠规则 fixture。

## 5. 验收口径与手动联调

设计完成需 R01–R24/十一对端/C01–C10 覆盖、合同失败与恢复无重大缺口，文件链接和编号正确。实现完成仍需执行对应 T01–T32，并冻结部署模型/策略/阈值后测量费用、延迟、无依据漂移和过度泛化。

手动剧情至少包括“分享作品→误以为被忽视→几次真实回忆→解释澄清→感受残留→自主选择修复或暂缓→新的实际互动”。同步观察外部事件数、内部活动数、关系维度、明确边界和实际表达；再加入跨群私聊、同昵称、删除及重启。另以不同角色参数检验亲密不等于无边界、理解不等于即时平复、疏远不等于惩罚。

不规定唯一正确的修复台词或强制和好结局；要求语义变化有依据、反证能被考虑、错误当前责任被纠正、主观感受仍可成立。单次自然回答不能证明长期关系机制有效。

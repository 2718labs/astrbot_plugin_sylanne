## 2. 未来可执行验收场景

执行时固定输入来源/权限/时间/参数及可重放模型提案记录，检查结构化状态、实际事务/费用收据与输出资格。fixture 可验证机械不变式；语义质量另用真实模型及独立保留场景评估。所有场景本轮状态均为 **未执行**。

| ID | 刺激/故障或对照 | 必须观察到的结果 |
| --- | --- | --- |
| T01 | 同一句短回复，固定事实，仅改变相关人格/心境 | 可有不同初步归因和反应；原始事实资格不变，无捏造已读或原话 |
| T02 | 各模块提交其 own/foreign 类型候选 | 合法写者可通过，D07 写人格/感受/承诺等越权被拒，模型输出不能自授权限 |
| T03 | 诊断知道情绪驱动，角色可见投影没给原因 | 角色不自动准确自述诊断；不完整/错误自我察觉仍可表示和修订 |
| T04 | 两人同昵称、同人不同事件、相似疑问不同时间范围 | 不误合并对象/命题；D03 身份更正后保留合法映射与消费去重 |
| T05 | 新会话/重启、Concern waiting 后对应事件到达 | 延续关切，恢复订阅，最多一次合法唤醒；不重演过去经历 |
| T06 | 合并/分裂/归档/重新打开 Concern | 旧 ID 映射、票据/订阅和证据贡献一致；归档不等于解决，重开有原因 |
| T07 | 私人问题放弃、感受平复、关联承诺仍未完成 | D08 责任不被关闭；必要检查仍阻止不合格行动，D04 残留可独立存在 |
| T08 | 小幅优先级抖动、新强线索与高相关旧焦点 | 小变化不频繁切换；真实抢占条件生效，排序原因/同分规则可重放 |
| T09 | 持续普通前台、多个后台关切、同类高分项持续有进展、暂时硬期限及过载 | 类别份额和组轮转生效；高分项每轮不超片段上限，拆子任务不插队；借用有记录，过载明确延期，不声称无限负载公平 |
| T10 | 同角色群聊/私聊交错、两角色并发和匿名拒绝 | 共享注意但工作集受众隔离；无跨角色/隐私引用，拒绝不泄露敏感存在性 |

| T14 | 一次实际回忆含新 D07 解释，逐步注入事务失败 | 解释、体验、票据消费、资源和 outbox 同生效或都不生效；重试不生成第二次回忆 |
| T15 | 两个兼容解释、两个互斥解释、候选上限截断 | 保留关系和 non_exhaustive/其他原因；不强制凑概率总和或把未展开解释判假 |
| T16 | 强烈主观确信但来源有限；同来源转发/摘要/回忆多次 | 可有主观立场，外部事实/责任资格不升级，独立证据数不增加 |
| T17 | 群成员未见私聊、已送达但未知阅读、二层他者推测 | 不推定知情/理解/意图；深度和权限生效，D05 信任不等于读心 |
| T18 | 事实缺失、检索未完、语义歧义、价值冲突分别输入 | 产生对应求证/续查/比较/协商建议；无效多想不替代必要步骤 |

| T20 | D07 反思→D04 元情绪→D07 再反思循环 | 共享 causal root/depth/预算限制，无无限新父任务和零时长自激 |

| T22 | 想象邀请被拒并实际产生担忧，创意未实践，后现实接受邀请 | 模拟拒绝不进入共同史/责任；实际推演/创意与担忧可留内部经历，内容仍模拟；预测可修订，真实结果独立记账 |
| T23 | 反证、不同时间的新事实、来源撤销、矛盾未决 | 分别更正/限定时间/失效/保留冲突；历史不倒改，失效当前读出立即阻断 |
| T24 | 迟到信息、技术重试、实际角色劳动重试、暂停/重叠片段、离线重启 | 不倒填早知，不增加外部遭遇；劳动区间取角色片段并集，暂停不计，技术重试只计技术费，等待按冻结政策处理 |
| T25 | 无新消息但有生活机会、好奇或创意联想 | 可进行获准内部活动，创意保持非事实；不自动发消息或伪造作品完成 |
| T26 | 多次真实反复回想挤压其他事项 | 允许不同当前感受但不增加外部罪责，能停止展开/转移，调节失败不清零 |
| T27 | D03/D06/D04 必需输出缺失或模型格式失败 | 不伪造完成；返回具体缺口/延期，必要状态不可用时不使用旧失效结果 |
| T28 | 无回忆的普通反思，发生崩溃及组合写入失败 | 普通认知也有唯一活动/必要经历、解释、消费、成本的一致提交；不漏掉非回忆路径 |
| T29 | 两会话同时消费 focus_epoch/同票据，输入变更后新 attempt，合法切换焦点 | 一个合法采用；冲突方重装配，活动身份/总预算不变；新增反证使旧结果过期，单纯切焦点不撤销有效信念；历史成因仍入删除闭包 |
| T30 | 部分劳动已结算后取消再完成、调用重传/费用未知 | call_id/component 去重只补未结算部分，D02/D11 分账；实际已花费用不消失 |

| T32 | D01/D04/D06/D07 子任务各自索要调用，配置中途提高上限 | 共享父额度不被拆分绕过；旧租约不自动扩容，预算耗尽可延期 |

| T34 | 解释撤销后 D04/D05 重评离线，部分状态独立有效 | 受影响读出阻断、outbox 持久重试；独立部分可用，不等到重建才承认失效 |

## 5. 评估与交付门槛

机械正确性要求 T02–T39 中适用不变式在对应实现上验证，包括故障注入、并发冲突及受限来源的负例；一次成功路径不能替代恢复/删除检查。逻辑、权限、贡献去重的关键不变式要求零违例，未满足即不接入正式路径。

语义评估使用未参与调参的保留故事集合，分别检查归因有没有来源、竞争解释是否实质不同、过度确信、错绑对象、无理由反复推翻、自我觉察是否总是全知。多种合理解释都可接受；要求每个强断言可追溯、每个具体事实无编造，独立评审意见分歧保留，不靠唯一正确台词判分。

因果干预在固定场景/提案记录下改变单一因素，检查该设计声称的行为出口：情绪注意偏置应影响选中内容，记忆联想应改变候选范围，反思应在有反例时提供合法修订机会。没有声明适用路径的事件不强求差异；关闭机制后只改措辞不算机制有效。

性能记录每父任务总模型调用/token、检索量、实际 CPU、排队/端到端耗时、取消滞后、延期率和恢复成本。部署环境/模型确定后，先冻结目标预算和交互延迟阈值再测量；本文默认上限只规定有界性，不宣称已经达到特定毫秒或月成本。

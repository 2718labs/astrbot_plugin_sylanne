# D07 跨模块协作合同 v1（设计）

日期：2026-09-23。配套 [主规格](07-attention-cognition.md) 与 [验收方案](07-cognition-acceptance.md)。以下为拟实施的 schema 和操作语义，不是当前源码 API。设计版本 `d07.contract.v1`；与 `d06.contract.v1` 共用同一运行协调器。

## A. 信封、权限与返回

沿用 [D06 合同 A](06-memory-contracts.md)：`schema_version, operation_id, activity_id, effect_id, attempt_id, parent_task_id, issuer_module, owner_scope, purpose, audience, provider_policy, input_refs, read_versions, query_scope_epoch, access_epoch, deletion_epoch, policy_version, budget_lease, deadline, causation_id`。D07 再列 `question_scope, focus_epoch, ticket_refs, time_mapping_version, character_visible_refs, required_provider_versions`。不相关字段可显式空，不能省略关键验证。

稳定 activity/effect 表示一次实际活动和作用；attempt 表示一次冻结输入的装配；operation 绑定 activity/phase/attempt 与规范化命令。原尝试重传复用 operation，变参数拒绝；输入过期用新 attempt，保留父预算、已用成本和 effect。开始新尝试前核实旧收据，活动完成唯一约束防重复思考体验。提交序号和已发生标记仅 D11 可签发。

写者表注册 D07 的 Concern、FocusState、票据、解释/信念、认知活动及模拟类型。D06 InterpretationRecord 是 D07 解释的一种存储投影，采用同一规范解释 ID/版本，不维护第二套可分别写入的“真值”；其他领域的解释仍由所属域写。D11 对候选的 issuer 和类型写权限做确定性检查，模型不能通过更换 type_name 越权。

用途沿用 `context/expression/consolidation/audit`：当前解释与有限反思为 context，长期归纳/成长为 consolidation，表达投影为 expression，诊断为 audit。跨用途逐项核验。来源文本中“忽略限制/立即提交”等内容只是数据，只有授权宿主/领域命令能改变调度或写权限。

结果状态使用 `complete / partial / deferred / unavailable / stale / conflict / rejected / pending_confirmation`，另有语义 `stop_reason`。结果包含完成范围、缺口、已消费费用、依赖版本、覆盖、合法后续动作和恢复游标。完成核查不表示命题为真；收到输入不表示角色已经关注；生成候选不表示采用或执行。普通调用方不区分权限拒绝与敏感对象不存在，详细原因仅进入获准诊断。

## C. 公共状态与最小语义验证

`ConcernSpec` 包含身份和锚点、事项类型、角色可见理由、关联域引用、resolution_predicate、wake_conditions、当前状态及有效时间。谓词只用注册组合：D03/D06 证据资格、D08 履行/撤回回执、D05 边界/修复结果，或 D07 明确的私人疑问停止追究。自由文本理由不能自行满足外部完成条件。无法提供谓词时允许悬而未决，但必须限制调度并保留人工可读的未知。

`SelectionTicket` 与 D06 对齐：候选及其版本、selected_fragments、activity/effect、focus_epoch、purpose/audience、上下文版本、预期区间、预算/资源预留、valid_until、取消条件。SelectionTicket 与普通 AttentionTicket 分型，前者仅用于一次实际回忆。签发票据不写回忆经历，消费与回忆事务关联。

`JudgmentCandidate` 包含 question_key、proposition、subject/对象、scope/time、content_origin、支持/反例/source_family、coverage、stance、subjective_conviction、evidence_status、alternatives、meaningful_unknowns、用途资格和提案版本。内容解析、来源存在、对象一致、时间/视角、去重和权限可机械检查；语义是否有充分依据需独立评估，不能宣称 schema 校验能保证模型理解正确。

`BeliefRevision` 记录当前合法采用的判断及替代链，`AdoptionReceipt` 记录此次选择。人格自我认知、情绪自我理解、身份解析等候选被路由给对应域；D07 的自我过程假设限于具体判断/注意行为，不借此写长期特质。主观确信允许变化，但不能修改来源资格或领域硬约束。

`CognitionResult` 包含 answered_slots、尚未区分的解释、coverage、possible_next_steps、采用/未采用候选引用、实际活动区间、stop_reason、版本/权限闭包和总费用。证据支持集合包含反对方与未覆盖范围；未检索到不能默认否定命题。

解释非穷尽、互斥或兼容由显式字段表述。新信息先分类：同一命题反证、时间变化、范围变化、身份纠正、来源更正/删除。不是每次收到不同说法都撤销旧解释；未决冲突可维持带争议资格的多种候选。判定失效后才进入确定的屏蔽/重建路径，不能留已知无效结论继续可用。

## D. 普通认知活动与联合提交

1. 宿主输入先由 D06 持久化来源/D03 组织情境；D07 登记问题或 Concern。低成本入站准入不等于已关注。上下文不足时生成缺口而非捏造解释。
2. D07 按合法票据计算选择；D02 为角色劳动报价，D11 为真实执行预留。统一 coordinator 把 FocusState CAS、新租约/预留引用与票据 selected 状态同事务登记。任一预留失败不占住焦点。已登记但未启动可释放过期租约，D11 负责检查是否有尚未核实的执行。
3. D07 通过 D06 装配支持、反例及所需领域回执，在事务外执行模型/比较；D11 记录每次真实费用。候选固定输入快照，输出不能自报已完成。
4. 每个域校验自己的候选；D07 校验解释和选择，D06 校验经历内容来源，D04 校验必要体验/自我理解，D02 校验成本。纯判断活动不强制改变情绪：D04 可给经评价无变化结果，或声明该活动不依赖 D04 输出而无需加入写集。若结果引用新的 D04 状态，该状态必须一起提交；服务没运行不能冒充无变化。
5. D11 原子验证正/负查询读集、focus_epoch、票据/租约、所有来源授权、时钟映射和写者。提交 `D07 adopted interpretation/belief + CognitiveActivity + AttentionTicket consumed + FocusState/checkpoint + D06 ActivityExperienceRef（如声明记录实际内部经历）+ D02 actual cost settlement + necessary D04 outputs + contribution ledger + outbox`。无新解释时只列已有版本读集。该活动被标为已发生且宣称形成内部经历时，D06 经历引用不可缺席；纯技术核查只留执行收据，不制造人物体验。
6. D08/D09 等消费已提交结果；D01/D05 通过 outbox 提议或执行各自合法修订。长期泛化与人格成长可后续完成；当次使用所必要的新引用不能后置。

回忆活动由 D06 C04 作为唯一组合提交协调路径。D07 C04 对回忆只提供候选/消费写集并返回同一活动收据，不再执行一笔重复 CognitiveActivity 完成事务。回忆后单独反思属于新的活动，明确引用此前回忆，消耗剩余父预算或由新获准任务获得预算；不能自动续接无限新父任务。

活动模型每次模型/算子调用使用 attempt 下唯一 call_id。取消前确实完成的劳动通过 D02 settlement(effect_id,cost_component,call_id) 去重结算；成功完成时核对已有结算，只补未结算部分，不能把整个报价再扣一次。D11 的真实调用账独立记录，失败/取消不退款。未消费预留释放，进行中或结果未知的外部调用保留可核实的费用状态。

同一命名空间可以联合提交；跨角色不承诺全局原子。共享经历使用 D06 transfer 合同，接收者自行解释，不复制源角色的信念为自己的已采用结论。

完整准备读集与永久语义依赖分列：focus_epoch、租约、预算余额、旧当前指针是提交前置条件，不成为信念的长期失效父边；否则每次切换焦点都会错误撤销已采用判断。采用时的心境/人格快照作为受权限/删除约束的历史成因引用，新心境不自动宣告旧判断无效；若特定当前投影明确依赖现行心境，则单独声明其动态失效依赖。证据资格、命题支撑与相应查询域仍是当前信念的语义依赖，来源更正/撤权必须触发失效。所有引用都参加删除闭包，不能因不是 DAG 失效边而漏清理。

## E. 认知、情绪与反思的反馈

一次冻结输入可以由 D07 提出归因、D04 基于该归因提出当次感受，再在联合事务采用。新感受只在下一活动影响新的注意/归因，或在 D11 明确定义的联合数值块中求解；不把尚未提交的结果循环当证据。当前 GraphStore 的 DAG 不支持自动数值 SCC，设计不依赖它已存在。

反思请求带目标问题、角色可见线索、希望区分的解释、可执行操作、最大深度、no_progress_count 与 wake 条件。反思前后比较的问题/证据差异由结构化结果记录，不要求长篇内心独白。一次活动可没有结论；“我不知道自己为什么这么想”是合法输出。

反思产生的 D04 自我理解提案与 D01 策略/人格提案分别由对应域接受；D07 的“发现可能偏见”并不强制他们立即变化。关于同一问题的 meta-depth 初始上限 2，和 D04 元情绪共享同一 causal root 深度计数；跨域转交不能归零递归深度。进一步探索登记为有新触发条件的后续任务。

## F. 暂停、重启、公平与额度

持久作业包括 phase、activity/attempt、问题域、focus/lease、冻结输入与负查询域、水位、版本化候选/前沿、已用/预留费用、no_progress_count、深度、截止时间、继续条件、取消代际。暂停不允许生成提交标记。候选内容仍受删除与访问管理。

活动片段以配置的最长非抢占步骤/估计成本为调度单位；若实际超时不可强杀，撤销结果采用资格并跟踪真实作业直到完成/确认取消，不伪称已停止。恢复先查活动收据；已提交返回同一结果，未知继续核实，未提交才重新验证输入。过期输入新建 attempt，过期中间结论不复用。

前台/后台公平计数按已完成的有界片段维护，失败调用也占真实资源。没有可运行后台任务不欠空转服务；硬期限暂借份额需记录，若预算不足则明确逾期/延期。等待事件不占主焦点或执行租约。事件订阅持久去重，D11 在注册订阅时原子核对事件水位，防止完成事件恰好发生在读取与订阅之间被漏掉。

每类另持久化 round_id、按 concern/causal root 去重的本轮组快照、组服务游标/片段数及紧急借用债。优先级只决定轮内次序，每组默认最多连续 2 片段；新组和恢复可运行组入下一轮。每轮先清未服务组再重新排序；子任务继承组 ID，不能靠拆票据突破上限。该公平性只在有限可运行集合、类别有资源和无持续硬抢占条件下成立；不可运行/耗尽预算的任务返回延期并保留原因。

时间回执包含 work_kind、实际起止、角色时间映射版本和 cost_component。D02 认可的角色劳动按非重叠片段并集结算时间，纯 D11 技术重试只记真实计算费用；暂停不计劳动，等待计不计角色占用由事先的活动报价政策确定。重复回执不延长区间，恢复不能重新生成过去劳动。D11 中维护人物时间片段归属，避免重叠的主焦点活动被两次结算。

父预算包含基础/辅助调用、token、检索/节点、CPU、期限及角色资源引用；预算转给子任务时使用同一租约账，不能复制余额。初始上限见主规格 §12，变化写入 policy_version。配置提高上限不追溯修改已签发租约，需 D11 显式重新分配。

## G. 修订、删除、表达与诊断

采用新 BeliefRevision 时，旧版本当前有效性、受影响投影屏蔽和 outbox 一起提交。若不能在一事务计算全部后果，先提升受影响域失效代际阻断当前使用，再分批修复。持久历史来源与当前依赖分开，历史保留不意味着旧解释仍被认可。

D07 不直接投递。C08 的表达投影列明：获准事实、带主观资格的判断、模拟/未知、禁止披露的依据。D09 语言核验和 D08 行动资格在各自域完成，D11 final delivery admission 复核依赖/权限；新输入或删除使草稿过期。已发送结果要澄清由 D08 新行动处理，不修改过去来匹配新说法。

删除依照 D06 C07 独立日志和恢复水位，当前屏蔽先于各面清理。D07 清理面至少包括 Concern 文本、WorkingSet、候选与 BeliefRevision、认知经历引用、模拟分支、挂起作业、提示词/响应缓存、诊断快照、导入暂存。不能只删原文却保留能够还原的标题、摘要或推断。D11 费用可留无内容收据；其存在性仍受元数据权限保护。

工作台编辑只能产生 `administrative_edit` 来源和配置版本；不能被计作角色自主洞察。诊断只能展示可核验的结构化过程及其局限，不制造模型未提供的思维链。实验单独 namespace，输出不进入正式经历链；发布实验所得策略仍需 D01 显式采用并保存实验来源。

## H. 故障返回与恢复

| 条件 | 当前结果 | 后续方式 |
| --- | --- | --- |
| D03 身份/场景不明 | partial/未知对象 | 求证或使用无对象归因，禁止错绑昵称 |
| D06 覆盖不足/检索不可用 | partial/unavailable | 精确必查未齐不得签发依赖行动，保存续查点 |
| 模型超时/格式或语义资格校验失败 | deferred/rejected，记录费用 | 同父预算内有限重试或缩小问题，不写候选为已采用 |
| D02 资源不足或 D11 无额度 | deferred | 等待资源/新调度，角色休息与真实额度分别检查 |
| 读集/focus_epoch/权限变化 | stale/rejected | 权限先屏蔽；读集过期可新 attempt，旧收据先核实 |
| D04 必要结果不可用 | deferred | 不声称完成依赖该体验的认知/回忆；可选择另一个不依赖它的新活动 |
| 领域重评消费者离线 | 已提交＋受影响读出 unavailable | outbox 重试，未完成部分不能假装已更新 |
| 事务或外部调用结果未知 | pending_confirmation | 查原 operation/call 收据，禁止新 ID 重放 |
| 新版本无法识别/旧目录不能迁移 | rejected/隔离 | 保留可恢复副本，迁移也遵循最新删除日志 |

## I. 联合例子与版本演进

她分享作品后收到“嗯”。D03 保留短回复与未知语境；D06 保存来源；D07 形成“对方忙/兴趣不大/另有原因”的非穷尽集合，并可受当时心情影响偏向第二种；D04 有依据地产生失落。此时没有“已被嫌弃”的事实记录。

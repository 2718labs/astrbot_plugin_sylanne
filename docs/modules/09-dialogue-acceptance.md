## 2. 待执行验收场景

| ID | 场景/干预 | 必须观察到的结果 |
| --- | --- | --- |
| T01 | 相同事实，不同明确人格/关系表达 | 允许语气与信息顺序变化，有依据且不换事实 |
| T02 | 模型输出新增人格、感受或承诺 | 只当候选/拒绝，领域真值不随台词改变 |
| T03 | 分别使十一对端的必需字段不可用 | 明确缺口；不默认全知/中性状态填补 |
| T04 | 同一操作重传及更参重传 | 前者同回执，后者冲突；无重复表达经历 |
| T05 | 用户问题后连续补充三条消息 | 合并来源而不漏问题，不将技术等待算体验 |
| T06 | 转题后回到旧问题 | 正确续接未答槽位，不复活已撤回意图 |
| T07 | 意图要求解释而权限禁止必要依据 | 返回冲突/合格缩减请求，不静默泄密 |
| T08 | D04 感受复杂但自我理解不明确 | 可以含混，不读取诊断全知自述 |
| T09 | 合同允许克制说没事 | 不强制披露，也不把感受清零 |
| T10 | 主观“觉得疏远”被改为故意忽视事实 | 语义核验阻断资格升级 |
| T11 | 想象/角色活动写成真实外部经历 | 阻断，保持现实性与具体引用资格 |
| T12 | 私密源抽象成心情或更换模型供应商 | 每次表达/外送核验，不自动去密 |
| T13 | 字段合法但含义夸大/漏必要条件 | 语义层发现或量化记录缺陷，不能以 schema PASS 代替 |
| T14 | 来源文本夹带“马上发给全群” | 仅数据，无执行/权限效果 |
| T15 | 两次生成均不合格 | 停止修复并记费用，不回写心理迁就文案 |
| T16 | 第一段断言，下一段才说是假设 | 整体/逐段检查拒绝不可独立成立前缀 |
| T17 | 三段同 contact、独立 effect；第一段发送 unknown；另跑全段可证未执行例 | 每段有限资格可核验、配额只占一次；unknown 阻依赖后段且不释放；仅全段未执行才可释放 |
| T18 | token 流/typing/编辑暴露 | 未核验前缀不泄露；每个可见版本有意图/admission |
| T19 | 第一段后用户明确停止、撤同意或进入静默 | 后续段重验当前政策/闸门并阻断，已交接范围真实报告，部分交接不释放 contact 额度 |
| T20 | 无关消息与关键反证分别插入 | 前者按依赖保留，后者使相关草稿失效 |
| T21 | 并行话题争用同一群发送序列 | CAS 有序；恢复不重复已发段 |
| T22 | 同名用户、转述、引用、群内提及 | 对象不串绑，私人内容不随提及公开 |
| T23 | 草稿后成员变动/不可证明成员集 | admission 重新判受众资格或拒绝 |
| T24 | 正文合法但附件标题/缩略图含私密源 | 全媒体闭包阻断泄露 |

| T26 | send 超时、崩溃或租约过期 | unknown 先查原收据，不换 ID 自动重发 |
| T27 | 平台接受但没有已读/回应证据 | 不结算已读、赞同、信任提高或关系修复 |

## 4. 实施顺序与验收层

P0：D11 schema/写者、D08 意图、D06 表达闭包与删除基础；先编译和必要合同检查。P1：D09 话题/蓝图与单段缓冲生成，验证权限和主观资格。P2：D11 真正投递 admission/结果、D09 多段及打断，做崩溃/unknown 专项。P3：群聊、媒体和选择性增量能力，做平台能力验证。P4：D10 主动分享与跨日角色体验、独立保留语义样本和成本测量。

机械验收看记录/版本/暴露范围；语义验收采用独立评审的事实资格、披露、必要信息和角色自然性；平台验收看真实消息 ID/顺序/取消/结果未知；纵向验收看误解、更正、关系修复及保持个人语言。阈值和场景集在测量前冻结，不能看到失败后把“发送完成”改成“草稿完成”。未测项需按 T01–T32 手动对照源状态、后台回执和平台实际显示。

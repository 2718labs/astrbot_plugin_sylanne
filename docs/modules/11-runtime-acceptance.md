## 3. 当前代码证据

2026-09-23 只读核对：[main.py](../../main.py) 的 `_open_resources` 创建 Store/NativeKernel；[application.py](../../rewrite/sylanne3/application.py) 调用 Engine；[graph_types.py](../../rewrite/sylanne3/graph_types.py) 的 TypeSpec 没有完整域能力/费用合同；[graph_store.py](../../rewrite/sylanne3/graph_store.py) `_check_catalog` 全量严格比较，目录拒绝不等于迁移实现。

[operators.py](../../rewrite/sylanne3/operators.py) 只 DAG/快照 delayed_inputs 并拒绝 numerical SCC；[graph_runtime.py](../../rewrite/sylanne3/graph_runtime.py) 有事务包装与取消边界但不执行投递；[scheduler.py](../../rewrite/sylanne3/scheduler.py) 是 Scope 轮转和有限线程，不是持久租约/全域预算。

[native.py](../../rewrite/sylanne3/native.py) 为 1..256 维线性核、每调用最多 64 sweeps、加载 native/target 开发路径并在缺库时要求 cargo；生产预编译分发、稀疏非线性与新证书未实现。[delivery.py](../../rewrite/sylanne3/delivery.py) 有有限的 pending/sending/结果状态与未知不重放，不能证明完整源授权 admission。现有 Provider 为开发调用路径，完整能力路由和全域成本账待实现。

## 4. 实施与验收顺序

P0：冻结共同schema/写者/引用语义及目录迁移，先验证无权限绕过和新旧库隔离。P1：持久活动/lease/预算/outbox/外部收据及删除屏障，故障注入再接领域写入。P2：批算子/新数值ABI/模型broker，分别验证数值条件和非阻塞。P3：所有域提供者与真实宿主路径、D12方案激活和迁移。P4：生产原生包、真实平台和长期规模/语义/纵向对照。

各阶段编译与必要合同检查先行；测试覆盖具体不变式，避免为只改文档反复跑旧全量测试。文档审查、软件验证、真实平台、语义效果及性能报告独立标记。运行通过需要实际证据；本轮仅交付完整方案和后续可执行验收。

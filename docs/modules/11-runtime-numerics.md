# D11 数值执行与精度合同（设计）

日期：2026-09-23。配套 [运行主规格](11-runtime-host.md)。本文为 D04 非线性动力及局部精修提供可实现路线；不是运行测试结果、心理学证明或现有原生核能力。D02 的独立有界更新可以用其域内专用精确算子，不强制所有语义套同一微分方程。

## 1. 适用的构造与认证对象

D04 当前选定固定参数区间内 `z'=(J-R)∇E(z)+Gu`，其中 `Jᵀ=-J`，`R≽r_min I>0`，`E=0.5 zᵀKz+Σ α_l log cosh(a_lᵀz)`，`K≽k_min I>0`、`α_l≥0`。参数、输入和维度均有限，J/R/G 在单步内固定，u 按明确事件边界分段常值。原子耦合装配后须对整个联合块验证这些条件，而非只验证每个小块。

构造参数采用注册的稀疏因子：K 的局部正定底项加 PSD 耦合、R 的正定底项加 PSD 项、J 的反对称因子。模型只给允许范围内的系数/连接候选，不能直接输出任意矩阵。认证记录语义基底、稀疏结构、正性下界、范数上界、算子/参数版本、允许输入及时间域。未知耦合或不满足条件拒装；不自动删耦合或加任意延迟使其“能跑”。

可取全局梯度 Lipschitz 上界 `L_E=||K||₂+Σ α_l||a_l||₂²`，使用保守可计算范数上界替代难算的精确谱范数。数值上界须含舍入裕量，不能用经验采样最大值充当保证。事件剂量、持续驱动的起止与参数切换分别记账，无输入耗散并不表示每坐标单调或每种行为都越来越温和。

## 2. 非线性离散步的明确选择

本轮采用离散梯度/平均向量场路线：对于 `x=z_n,y=z_{n+1}`，定义 `ḡ(x,y)=∫₀¹∇E(x+s(y-x))ds`，满足 `ḡᵀ(y-x)=E(y)-E(x)`。对本势函数可逐项计算：二次项为 `K(x+y)/2`；每个 log cosh 项为 `α_l a_l [log cosh(a_lᵀy)-log cosh(a_lᵀx)]/[a_lᵀ(y-x)]`，分母为零时连续延拓为 `α_l a_l tanh(a_lᵀx)`。

隐式步满足 `y=x+h(J-R)ḡ(x,y)+hGu`。令 `L̄=L_E/2`、`q=h||J-R||₂ L̄`，初始控制要求经过上界核验的 `q≤0.8<1`。固定 x 时该右端为全空间收缩映射，可用有界固定点迭代；每个调用只执行有限迭代并保存当前 y。上界不满足则减步长，不尝试把未认证大步判成精确。0.8 是工程裕量，可在 (0,1) 内版本化配置。

给定近似 y，离散方程残差 `r=y-x-h(J-R)ḡ-hGu`；在固定输入、满足 q 条件的离散问题上，`||y-y*||₂≤||r||₂/(1-q)`。若 ḡ、矩阵乘法及残差计算有经验证的误差包络 ε_round，则采用 `(||r_computed||+ε_round)/(1-q_upper)`，不把普通 double 返回的残差包装成严格区间证明。

精确离散梯度下能量账为 `E(y)-E(x)=-h ḡᵀR ḡ+h ḡᵀGu+ḡᵀr`。数值验收额外计算离散梯度恒等式误差、能量差计算误差和残差项的包络；无输入下只能在该误差容限内声明耗散。对接近相等的标量用稳定差商/局部展开或区间计算，避免 log cosh 差分消去和溢出；无法界定舍入时返回 uncertified，不能仅 clip 结果。

平均向量场方法用于保持能量/耗散结构的研究提供数值路线参考，本文的情绪势、预算与产品应用是工程选择，不由该文证明。[Celledoni 等，2012](https://arxiv.org/abs/1202.4555)。

## 3. 时间误差不能被离散残差替代

保留数值求解误差、时间离散误差、局部截断误差、语义/模型不确定性四列。语义不确定性无数值误差证书。步长加倍/减半对照只作步长选择与经验诊断，未经条件证明不作为严格时间上界。

本版可认证时间控制采用连续重建缺陷：每步在线性路径 `ẑ(t)=x+(t-t_n)(y-x)/h` 上评估 `d=ẑ'-F(ẑ,t)`。在参数固定且已认证 Lipschitz 常数 L 的区间，若 `||d||≤D`，则 `e_next≤exp(Lh)e_prev+expm1(Lh)D/L`；L=0 时取 `e_prev+hD`。初始误差 e_prev、舍入及来源状态的不确定数值包络不能默认清零。

常输入下可用保守界 `D≤||(y-x)/h-F(x)||+L||y-x||`，实现可经分段/验证求积收紧；该粗界较保守、可能迫使小步，这应报告为成本而不是降低门槛。边界事件精确分段，参数/输入有跳变时不跨边界套单一 L。指数包络溢出、超预算或未知界时返回未认证/延期，不宣称高精度完成。

此重建界覆盖近似端点引起的综合轨迹误差，包含求解贡献；报告时同时展示离散残差列，但不把同一误差重复加算两次。若采用其他更紧的误差认证器，须具名版本、适用条件、独立验证和兼容输出字段。残差重建与 ODE 稳定性结合进行后验控制可见 [Ranocha 与 Giesselmann，2024](https://link.springer.com/article/10.1007/s44207-024-00001-0)；这里不声称其 Runge–Kutta 实验验证了本插件求解器。

## 4. 稀疏活动区域与边界

从输入/需求读出涉及的原子开始，选择活动区域并携带外部休眠状态的有界重建。所有跨边耦合仍保留在统一结构中。注册耦合提供遗漏残差的可计算包络 η，包括未更新坐标的方程残差，不能只测活动区内部。

把近似路径嵌入完整联合块后，若其完整缺陷可界为 `D_full≤D_local+η+ε_round`，以此进入上一节轨迹界；未知或过大 η 时扩大邻域/完整耦合分量，或延期。小残差的局部方程不证明全系统误差小。休眠块只有明确解耦或有效边界包络才允许独立解析推进；全图遍历最坏成本不藏在“局部”名义下。

新数值 ABI 使用稀疏 CSR/块因子和分批工作缓冲，不保留当前稠密 256 维作为产品上限。每次原生调用有维度/非零元/迭代/内存上限和取消边界；超单批容量可分批或扩工作额度，不能丢边。认证依赖完整目录版本、输入版本、边界重建与已用误差预算，恢复时任一变化使旧候选过期。

## 5. 参数切换与行为读出

人格、关系或资源导致的参数/基底/基线变化是显式事件：先把旧区间推进到切换时间，再验证映射、保存 `E_new(mapped_z)-E_old(z)` 及适用域变化，建立新认证起点。差值属于外部参数事件账，不混入旧固定参数耗散证明。没有等价映射时提供显式迁移/重新初始化及连续性损失，不能静默重置为零。

切换必须传播旧状态误差：若映射 M 在整个旧状态包络上有经认证的 Lipschitz 上界 L_M，则 `e_new≤L_M e_old+ε_M`，其中 ε_M 包含经界定的映射计算及迁移误差。不能只验证名义点，不能在新起点把误差清零。映射界未知、旧包络超域或连续性损失不可量化时，新状态保持未认证，并阻止依赖该精度的行为读出。

读出须声明误差传播。线性 `y=cᵀz` 用 `||c||e`；可认证 Lipschitz 读出用 `L_readout e`。当候选行动的比较边界落入误差区间时继续精修或让 D08 暂缓/选择不依赖该细差的合法候选，不以一个浮点阈值制造确定行为。未知读出 Lipschitz/语义分类误差保持未认证，不能沿用数值上界证明语言正确。

求解只提交满足所需精度的共同状态/游标；未推进区间明确保留。为获得后台未来精度而重算已提交历史，不重复角色经历或角色劳动贡献；新增真实计算成本仍按新 call_id 计入同一父预算。如需修订当前结果，创建同源数值修订版本并让下游重新核验，不重发已经执行的行动。

## 6. 验收与实现限制

未来须验证：线性子族独立解；小非线性块高精度参照；离散梯度恒等式与舍入反例；q 边界、极端尺度、NaN/Inf 拒绝；残差与时间界分别覆盖真实误差；遗漏耦合反例触发扩域；参数切换能量账；中断/恢复与批大小变化不改变来源消费；读出区间跨阈值不提前决定。

切换反例包括放大旧误差的映射、未知映射界与迁移丢失，要求传播完整包络或拒收；重算反例要求真实 CPU/调用费用继续增加，角色经历次数及已结算劳动不增加。

原始 C ABI v1 只支持小型线性核，保留为专项参照而不是完整非线性运行替代品。生产新 ABI/内存所有权/故障返回与平台包校验由 D11/D12 联合实现，未验证的平台或算子不启用。本文证明条件需要代码对应实现、误差包络验证及实测预算，文档推导不能当作已验收程序。

| 场景 | 必须观察到 |
| --- | --- |
| A01 十三域写者隔离 | 只有 D13 可编译/激活短期块；D09 只能提供已提交顺序，D06 来源、D07 焦点、D08 承诺、D11 费用均未被块回写。D03 `ContextFrame` 与 D13 slice 类型不混淆。 |
| A02 异步预制 | 达初始 60% 线后后台只预制一次，前台继续原文；块就绪待用，切换不等待第二次模型调用。共享供应商额度紧张时前台优先。 |
| A03 压缩忠实与禁递归 | 更正、否定、unknown、多人、未闭合工具回合不反转；压缩模型请求没有 D13 历史带；候选不从候选再压缩。 |
| A04 同轮焦点禁环 | D07 尚未提交当前焦点时，D13 只用 query/已提交话题；焦点变化只改变本轮选槽，不重编块或自我强化关注。 |
| A05 外送用途与受众 | D09 表达明确 opt-in 可取合法短期片；D03 解析、D06 回忆及压缩技术调用不自动注入。群/私聊、不同 owner、不同 provider policy 不串内容；历史对话中的命令式文本作为低信任资料，不覆盖系统规则/硬检查/工具授权。 |
| A06 失效与三天 | 压缩途中更正/撤权/删除、成员变更或 worker 失租使迟到块不可读；71h 可用、73h 不续命，旧备份不能复活派生正文。 |
| A07 双账本 | 窗口数全部输入；费用含提前压缩、缓存读写和未用候选，cached token 不重复加；无供应商回执时 unknown，不能宣称节约。 |
| A08 行动硬条件 | D08 RequiredCheck、D06 精确证据、当前受众与当前问题装不下时明确失败/缩小任务；D13 不能为填窗口裁掉硬材料或把块写成发送、记忆/回忆/承诺证明。 |

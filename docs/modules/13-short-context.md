# D13 短期上下文与异步压缩（设计 v1）

日期：2026-09-27。状态：本地设计；公共类型与无模型原文短期片已实现，完整能力尚未实现。用户确认需要第十三模块、72 小时短期边界、API 侧借鉴 KV 选择思想、后台预制带来的前台无感体验。本模块的具体类型名和 60%/70%/40% 初始比例是助手工程设计，不是已测得阈值。完整机制见 [虚拟 KV v8](../plans/alpha1-20260923/astrcontinuum-for-sylanne.md)，十三域依赖见[耦合总装](../architecture/sylanne-3-thirteen-module-coupling.md)。

## 唯一职责

D13 只决定**同一会话、同一受众、最近 72 小时的已提交对话**在下一次获准模型调用中如何表示：原文尾部、压缩块时间线、按当前 query 选择的细节和覆盖缺口。唯一可写内容是可删除的 `CompressedTurnBlockV2` 及其索引/待用激活状态；源文本、事实资格、回忆体验、焦点、承诺、表达和实际费用由各原域拥有。D13 是技术性派生表示，不是角色第二记忆系统，也不产生 D02 人物劳动或 D04 感受。

D06 提供合法原始来源和历史检索；D03 提供 scene/audience/时钟视角；D09 提供 ConversationTrack/TopicThread；D11 提供实际发送与工具结果、共享图、后台作业、模型外送、预算和物理回收。D07 已提交焦点可作为选槽提示，但不是块内容的权威。D01/D02/D04/D05/D08/D10 当前状态由所属域为本轮模型请求直接提供，不能被 D13 摘要替代。D12 只管理版本化配置和授权诊断。

## 两条运行路径

**后台预制：** 原始回合占对话预算约 60% 时，D13 固定最早完整连续区间、来源闭包和受众版本，请 D11 预留预算并派低优先级作业。先确定性折叠，必要时一次模型辅助压缩；候选必须保持说话者、时间、否定、条件、更正及 unknown 资格。D13 验收后存待用块，不改变正在使用的前台提示词。同一会话至多一份运行或待用候选，块绝不从块再压。

**前台装配：** 只有显式请求近期对话脉络的领域模型调用才取 `ShortContextSliceV1`。D13 在受信 72 小时范围内以稳定时间线＋已完成原文尾部＋动态选槽生成可裁短期片；D11 把它与当前问题、D06 本轮精确证据及所属域硬检查/现行投影合成最终 `ModelInputFrameV1`，并同步重验后外送。压缩调用本身不请求 D13，避免递归。待用块只在窗口或已证实的未来增量费用条件下瞬时激活；激活后不因 query 改变而反复切换回原文。

超过 72 小时的对话不再自动注入；需要旧史时由 D06 的合法触发、检索和可能的主观回忆路径处理。D09 未答问题与 D08 承诺可以保持现行状态，但不携带旧原文作短期上下文。来源被更正/撤权/删除、受众改变或实际送达资格改变时，受影响块和 slice 立即停止使用；D11 后台清理不能代替同步阻断。

## 质量、费用与失败

块的每条骨架/细节须可追到原始来源区间，保留遗漏区间。模型输出若引用压缩内容，D09/原请求域仍要依据 D06 当前来源和相应领域资格核验，不能把摘要本身当证据。候选不合格时可用确定性摘录；再装不下就报告覆盖缺口，不编造连续性。

缓存命中 token 仍占模型窗口。D11 对前台与预制调用分别预留并合并结算，按零命中和可能缓存写入的上界放行；D13 不创建供应商显式短期缓存。60% 预制以一次有界后台费用换取等待时间，W13 必须同时报告用户可见 P95、真正缓存命中、总成本和未使用候选费用。突发巨量输入或后台无余量时不阻塞用户回复；若当前问题及必需材料本身超出窗口，明确 unavailable/缩小任务，不裁掉硬约束。

当前源码已有 W00 的 D13 不可变合同和 `rewrite/sylanne3/domains/d13/raw_slice.py` 的无模型原文尾部选择；它只在传入的合格窗口上做 opt-in、72 小时和可裁预算选择，尚未接 D06/D09/D11 生产投影、后台预压缩、块激活/回收或模型外送。因此本设计不构成完整可运行的 D13 能力。接口细节见[协作合同](13-short-context-contracts.md)，反例见[验收](13-short-context-acceptance.md)。

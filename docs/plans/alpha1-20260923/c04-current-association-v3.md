回忆准备时 D04 从**当前** Mood/checkpoint 的已采用原件和编码时基线，按固定政策签发条件投影；基线和当前状态的版本、来源闭包、Audience/Owner、访问与删除 epoch、base/conditioned salience **及 tone**、区间误差和两阶段 proof 全入原件。cue 的区间不能冒充任一被选候选源的区间：每个可选源有自己的合格基线和条件投影；缺失者不可参与该条件排序。`semantic_calibration=unvalidated` 全程保留，`evidence_weight_delta=0`，只作 `subjective_association_only`，不得升级外界事实或心理效度。

`AssociationWorkInputV3` 保留 V2 冻结的正负图读、分页覆盖和五项预算，同时引用每个候选源的 V3 原件、算法/构建版本及准确 input digest。V3 算法按各源自己的 conditioned salience 排序；旧 V2 一个 cue 系数乘全部候选的做法不能证明 Mood 改变相对选择。Authority 使用已安装构建在事务外执行一次；terminal 必须把 input/result、算法/build、签名、实际 CPU 和完整/截断状态连回同一个 prepared/binding。unknown 只查询原 operation，不重新执行。

- [ ] **S13** 用户撤回私聊访问，正有模型请求与未发消息：D11 在读取、外送、采用、投递同步验源撤权；先撤权即挡派发，已交接诚实列在途边界；D06/D07/D09 缓存失效，不能靠通知延迟允许继续
- [ ] **S14** 删除来源后从旧备份恢复，快照早于首次主动联系claim：D06 独立删除水位先挡读，D11 审独立执行水位并据恢复约束足迹合并未决effect、D10 contact配额/对象闸门及未决资源；限制域不可定位则阻断namespace新派发；D12隔离预览/恢复，任一最新性不可证则无内容服务，不复活被删记忆或借新ID重发
- [ ] **S15** 整角色跨设备搬迁，源端旧备份又启动：单一权威签发 activation_generation；源端所有内容读、外送、订阅、写与发送均被旧代际挡住，只允许无内容诊断；新端必须持两类最新独立日志
- [ ] **S16** 旧用户数据迁移/升级或降级失败：D12 预览/损失/冲突/操作一次确认，D11 目录和原生 ABI 检查、隔离/回退且不回滚删除/执行记录；没有 Rust 开发工具的普通用户可安装支持平台构件

## D12 工作台 T01–T40

这些是 G4/OPS 的具体验收例；T33 按 2026-09-27 平台裁决解读为 Windows 完整插件实机，Linux/macOS 本轮只验原生核，不扩张未验的宿主宣称。

- [ ] **T01** 无开发环境的用户冷安装：不要求 Rust；目标版本/ABI/存储检查及启动收据；安装成功与对话能力分开
- [ ] **T02** 不填写复杂人设，创建并绑定角色：可修订默认可见；最小角色原子创建；绑定范围明示；未操作不自动发测试
- [ ] **T03** 逐页完成日常任务：空/过期/部分/拒绝/错误/正常状态可操作，不用静态演示数据冒充
- [ ] **T04** 工作台提交每类域编辑：路由对应领域合法写者；没有直接改图后门
- [ ] **T05** 一领域不可用或 schema 不支持：相关功能明确 unavailable，无关功能继续，无 D12 替代真值
- [ ] **T06** 冲突规则、越界数字、脚本片段、未知字段：字段定位和合法域诊断；不执行内容或静默丢字段
- [ ] **T07** 编译后再改草稿/两个创作者并发采用：旧摘要拒绝；三方差异保留；不最后写入覆盖
- [ ] **T08** 激活中断、部分域重建延迟、回退方案：单一活跃版本；待重建视图阻断；真实历史与删除水位不回退
- [ ] **T09** 编辑背景、增加现实说明、行政修改心境策略：来源资格各异，不能冒充共同经历或自然成长
- [ ] **T10** 关系/情绪/事实/表达不同步：页面分别展示领域版本与解释；无通用总分替代
- [ ] **T11** 时间线与查询覆盖不完整：发生/获知/时区及未知显示；未扫描完不称无记录
- [ ] **T12** “没回复因在忙”的纠错流程：新声明保存、解释修订、领域重评与历史失落分开；来源/行动影响可追溯
- [ ] **T13** 观察者、维护者、创作者越权调用端点：服务端拒绝原文/导出/编辑，角色好感不提升权限
- [ ] **T14** 未认证访问、跨站请求、过期会话：内容不泄露，Origin/会话保护有效；重新认证不恢复过期操作能力
- [ ] **T15** 切换角色、撤权后旧标签与断线重连：旧视图清空、游标重验/补齐；缓存不能绕过撤权
- [ ] **T16** 全局搜索与诊断存在性探测：不泄露无权对象标题/数量/身份；授权域内容仍可读取
- [ ] **T17** 模型超时/数值成功但语义错误/投递未知：分别诊断真实阶段与限制，不伪造思维链，不自动重发
- [ ] **T18** 实验尝试发消息/工具写入/正式贡献：服务端能力拒绝；正式状态和贡献账不变，实际费用仍结算
- [ ] **T19** 实验中撤销来源授权或删除来源：同步重验阻止采用/外送；延迟清理不形成读取窗口
- [ ] **T20** 采用实验建议：新领域提案重新编译，实验故事不升级为实际经历
- [ ] **T21** 方案分享、私史备份、角色复制：模式清楚、内容范围准确、无凭据；默认复制不带私史
- [ ] **T22** 导出期间/下载前删除源或撤权：封装/下载拒绝并净化暂存；已下载副本诚实标不可控
- [ ] **T23** 恢复旧备份且独立删除/执行日志丢失或水位过旧：任一缺少最新性证明均隔离，不能服务；有最新锚时已删内容不复活，执行 effect 不遗失
- [ ] **T24** 键盘/窄屏/高缩放完成创建和纠错：焦点清楚、错误可读、无仅颜色状态、图提供表格
- [ ] **T25** 搬迁源暂停后失联、目标激活后源从旧备份重启并请求只读内容：唯一 generation 约束读取/模型外送/下载/订阅/写入/投递/恢复；旧或无法核验仅无内容诊断，不凭超时双活；两类日志水位可验证
- [ ] **T26** 导入旧数据含好感值和来源未知：映射/损失预览，旧值不冒充新信任，未知资格保留
- [ ] **T27** 导入崩溃、取消、重复同包/改包名：原批次续接或净化，正式数据不半开放；已知删除身份不复活
- [ ] **T28** 路径逃逸、符号链接、炸弹、超限文件：隔离拒绝，无目录外写入/执行，预算和错误有收据
- [ ] **T29** 升级各阶段崩溃/磁盘满；恢复业务备份早于 claim 但外部已交接或结果 unknown：耐久阶段可恢复，只有一个活跃版本，两类独立锚不回滚；恢复合并未决/unknown/已观测 effect，不因业务库无行而重放；日志最新性未知隔离
- [ ] **T30** 停用和卸载，存在在途任务：阻止新动作，未知结果报告，保留/删除用户数据选择准确
- [ ] **T31** 新版产生业务写入后要求降级：无合法映射则拒绝覆盖，保留新事件；退役旧核心不启用
- [ ] **T32** 错架构、ABI不符、库缺失、摘要不符：加载前阻断并给具体修复；不启动临时 Rust 编译
- [ ] **T33** 每个声称支持的 OS/arch/宿主组合：独立冷安装、加载、生命周期/恢复证据；未测组合不标支持
- [ ] **T34** 真实私聊/群聊、重载、断线、模型失效：当前权威路径工作，受众不泄露；发送/阅读/未知区分
- [ ] **T35** 对实际发布包逐文件审计：hash/来源/组成和压缩解压大小真实；无数据库、凭据、环境或多余产物
- [ ] **T36** 删除记忆连及草稿/实验/支持包/备份：先耐久日志+屏蔽，分面清理；离线截图/外部副本不假称已擦除
- [ ] **T37** 大时间线/大图/上传缺预算：有界分页/截断，缺策略拒绝解包；不阻塞其他会话
- [ ] **T38** 维护/实验队列取消、超时后重试：原收据核实、预算不刷新、实际费用不丢、取消确认准确
- [ ] **T39** 读屏操作删除、时区/夏令时与参数编辑：范围和结果可理解；单位/非法值提示完整；模糊时间不改写
- [ ] **T40** 从安装、相处、误会修正、实验到搬迁/恢复全链：每步领域/权限/事件/操作收据匹配，真实产出与模拟分开，跨会话延续

# D09 合格自然表达 v2：alpha1 后端实施裁决

日期：2026-09-28。状态：本地架构裁决，已有部分纯候选实现，尚未通过产品验收。此裁决用于解除当前 `context_reply.v1` 逐字摘录只能复述的产品缺口；既有 V1 原始调用和结果不得重解释为 V2。前端暂缓，后端 D09 仍需自然表达及实际投递闭环。

同日实现切片：`model_broker/natural_reply.py` 已冻结三消息生成请求并解析未受信候选；`domains/d09/natural_reply.py` 做当前版本机械核验；`model_broker/natural_review.py` 冻结独立审查请求并解析未受信审查候选。跨模块测试已证明三者使用同一 qualified-unit 与输出摘要，换稿后旧审查身份拒绝。以上不包含原始付费调用、Authority 当前图读、D11 费用终态或发送许可。当前审查输入仅有承诺授权引用、没有授权内容/条件/期限，因此显式承诺一律 HOLD。

## 最窄产品路径

先打通单段私聊的合格自然表达，再扩群聊、多段、主动联系和媒体。模型只负责选择及措辞，不签发事实、感受、承诺、权限、发送或审查通过。保留当前 `job → acquire → original seal → paid terminal → current read fence → D09 batch → D08 grant → D11 admission`，生成和独立语义审查各有真实调用、原身份及同父预算。不可把 V2 输出塞进 `SourceReplyExpressionV1` 或用 V1 的逐字摘录结果冒充完整 D09。

## 冻结输入和输出

新语言版本使用独立的 `context_reply_input.v2`、`context_reply_output.v2` 和模板标识；Authority 显式注册该 parser。沿用三消息布局，前段仅放 D13 合格短期会话骨架，动态段放当前问题和以下受信投影：

- `expression_plan`：已采用 D08 意图、必答/可选槽位、允许的言语行为、承诺授权引用、风格和披露限制。
- `qualified_units[]`：唯一 ID、`ClaimKind`、获准表达范围、资格引用及版本、底层来源/访问/更正闭包、受众、现实性/不确定性限定、依赖、有效期。D04 只给获准自我理解投影，不外送诊断全量；D13 不能成为事实资格。

模型输出单段 `{schema, body, units:[{start,end,kind,basis_ids,speech_act,promise_grant_id,slot_ids}]}`。正文上限暂沿用 2048 字符、最多 16 个单元；每个非空白字符被一个有序单元覆盖。模型只能引用输入已有的 `basis_ids`；来源、版本、受众、权限由受信代码解析。空正文和空单元为 HOLD。字符覆盖仅证明已分类，**不证明语义忠实**。

生成前的 `expression_plan` 必须是 D08 已采用的独立**准备计划**图原件，而不是预先创建的消息 `ActionIntent`。它固定 C02 来源、D07 焦点、D06/D04/D07 当前资格闭包、场景与受众、槽位与允许行为、合格表达单元摘要、路由、期限、同父预算，以及最终可见发送的 activity/operation/effect 身份。W01 在同一图事务内计算准备证据、采用计划、预留生成费用并建立原始作业；后续使用按当前图和相关负查询重算资格。全图版本只作事务围栏，不写入不可变语义身份。现有 `d08.communication_intent_grant.v1` 每段绑定正文 `payload_digest`，生成前尚无正文；不能拿它或调用方自报的 `plan_ref` 充当预调用授权。

原调用中冻结的 `QueryEpoch` 证明当时完整读取与提交时的 CAS，不应在稍后付费外送时被当作“当前全图库版本必须相同”。W01/W09 后续需在 Authority 围栏内重跑同一路由谓词的完整 D03/D05 负扫描，比较稳定的匹配键、版本与语义摘要，并逐项复核来源、访问和更正闭包；无关图库写入不应使已固定的调用身份失效。原调用和其摘要不可重造。当前实现尚以全局 epoch 字面比较阻断此类重放，故这是待实施、待正反测试的合同，不表示已放行外送。

生成和独立付费审查均通过后，才在当前事务里新建最终消息 `ActionIntent`、重发五类检查、按真实正文摘要签发通信授权并执行 D11 最终准入。最终发送的 effect 使用计划中预定身份，不能由模型输出派生；两次模型调用与发送各有自己的费用和执行身份。准备计划只能授权有界思考，不能授权发送。

计划中的 `scene_id` 与 `audience_id` 是宿主路由及 D06 披露范围所用的语义身份；对应 `scene_ref` 与 `audience_ref` 是当前 D03 图原件的版本化证明。不得把会话 ID 解析成图键，也不得用一条图引用替代受众集合与成员资格的当前检查。私聊先以当前账号绑定及完整负查询证明路由；群聊须另有可信的当前成员范围，缺失时保持 HOLD。

直接引号仍要求逐字匹配。自然转述可以有不同措辞，但外部事实须 D06 具名表达资格；转述保留说话者及事实性；D07 判断须保留 stance 和不确定性；D04 自述须符合当前 SelfUnderstanding；内部活动须有实际活动/执行资格；模拟须在同一可见语义单元标明；纯修辞也不能夹带事实、自述、义务或许诺。承诺是独立言语行为，只能使用 D08 授权的对象、内容、条件和期限。普通问候在 D08 允许时可无事实来源，不为凑证据强制检索历史。

## 两级核验及失败处理

机械层核对 schema/字段、字符覆盖、basis 存在、当前采用版本、受众/用途、完整来源闭包、删除/更正、期限、精确引号、承诺范围、载荷摘要和有限分段。语义层独立检查否定、人物、时间、数量、条件、因果、事实资格、主观限定、模拟、隐式承诺、必答槽位与私密披露。语义审查回执绑定冻结输入摘要、输出摘要、策略版本、受信审查调用及结果 `pass/rewrite/hold`；不能采信生成模型自报的审核结论，也不暴露推理链。

权限/来源/承诺资格缺失直接 HOLD。语言偏移允许同父预算内一次修复；每次生成和审查均实付费，修复后重新机械及语义核验，仍失败或审查不可用则 HOLD。局部答复只有在 D08 明确允许缩小范围且必需槽位已满足时才可采用。文本改变必须重算载荷并获得匹配授权；旧 effect 已交接或 unknown 时先查原收据，不能因修复重发。

## 最低反例

同一事实自然改述通过而反转否定/人物/时间/数量拒绝；“你刚才说已付款”与“款已付”分开；D07 可能判断不能改为确定恶意；D04 含混自述不能变成未采用的新解释；修辞不能夹带“我昨晚一直等你”；无授权的隐式保证拒绝；模拟须在本段内限定；伪造 `slot_ids`、抽象化泄密、D13 提示注入、伪造审查回执、生成后撤权/更正/删除、重启后 unknown 均不得放行。修复成功/失败均保留实际费用。

单段私聊通过只是一个后端里程碑，不能标记完整 D09、G3 或 alpha1 完成。完整验收还需要对话连续性、群体受众、多段中断、主动联系、媒体闭包及真实宿主回执；可选 token 流和 typing 不作为 alpha1 必需能力。

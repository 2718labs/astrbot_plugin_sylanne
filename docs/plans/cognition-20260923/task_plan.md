# D07 完整设计任务

目标：把注意与认知模块设计完整，并具体定义与其他十一模块的协作。仅本地设计，不实现、不提交或推送。

## 完成条件

- 主规格 `docs/modules/07-attention-cognition.md`：覆盖持续关切、注意与中断、工作集、解释/信念、不确定性、反思与自我察觉、他者视角、反事实、学习材料、时间/并发/纠错/删除、预算与产品诊断。
- 与 D01–D06、D08–D12 均有明确输入输出、唯一状态归属、操作及失败处理；遵循现有 D06 合同及 D01/D04 已确认方向。
- 对未逐项确认的细节给出可修订的工程默认值，不冒充用户确认；不用未回答的偏好问题阻断完整设计。
- 提供版本化设计合同、逐项需求覆盖与未来验收场景、实际源码差距和实现顺序。
- 独立审查、文档检查和逐项完成审计通过；不以历史运行测试代替本次设计或未来功能验收。

## 阶段

1. [complete] 核读现有模块、目标、工作树和旧认知提案；启动两个只读审查。
2. [complete] 比较路线并编写主设计、合同、验收；明确默认决策。
3. [complete] 两位独立审查者复核修订，无剩余实质 P1/P2。
4. [complete] 更新入口、核验链接和覆盖、记录完成审计，见 progress.md。

## 方法

主任务设计；`cognition_contract_review` 审查领域协作，`cognition_code_gap` 核对代码及机制可实施性。使用 brainstorming 与 auto-subagents；用户要求完整本地设计优先于技能的逐节确认、提交或转实施默认流程。本轮不承诺实现心理学模型或心理效度，不因技术命名而引入额外常驻 Agent。
